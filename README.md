# ALIHEREGIVEAWAY BUG

This repository contains the uploaded WhatsApp and Telegram bot project.

## Configuration

Sensitive credentials are intentionally not committed. Set these environment variables before running the project:

```bash
export TELEGRAM_BOT_TOKEN="your-telegram-bot-token"
export TELEGRAM_ADMIN_ID="your-telegram-admin-id"
```

Install dependencies and start the bot with:

```bash
npm install
npm start
```

## Security note

Never commit bot tokens, API keys, session files, or other private credentials to a public repository. If a credential has already been exposed, revoke it and issue a replacement immediately.

The archive includes the main Node.js entry point, configuration, supporting JavaScript files, images, and the bundled JAR artifact supplied by the uploader.
